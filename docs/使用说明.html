STEP 1

申请麦当劳 MCP Token

唯一需要手动操作的步骤，之后全自动。约 3 分钟。

打开开放平台

访问 open.mcd.cn/mcp

用手机号登录

会收到验证码，直接输入即可。

激活并复制 Token

进入「控制台」，找到 MCP 服务的激活/授权按钮。点激活后会显示一串形如 ghp_xxxxxxxx 的 Token，只显示一次，立刻点「复制」。

💡 Token 是你的专属钥匙
只存在你本机的 MCP 配置里。Skill 调用时是直接向 mcp.mcd.cn 发请求， 不会上传、不会存储、不会转给任何人。
STEP 2

配置 MCP 连接

在 WorkBuddy 里填一次，之后永久有效。约 2 分钟。

打开连接器管理

WorkBuddy 左侧边栏 → 【专家 · 技能 · 连接器】（或点底部「＋」图标） → 右上角 【自定义连接器】 → 【配置 MCP】

粘贴配置（二选一）

仓库里提供了现成的 mcp-config.example.json：

{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer ${MCD_MCP_TOKEN}"
      }
    }
  }
}

方式 A（新手推荐）：把 ${MCD_MCP_TOKEN} 直接替换成真实 Token

{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer ghp_你的真实Token"
      }
    }
  }
}

方式 B（更安全）：保持 ${MCD_MCP_TOKEN} 不变，用环境变量注入

# Windows PowerShell
[Environment]::SetEnvironmentVariable("MCD_MCP_TOKEN", "ghp_你的真实Token", "User")

# macOS / Linux
export MCD_MCP_TOKEN=ghp_你的真实Token

保存并启用

点【保存】→ 点【启用】。环境变量方式需要重启 WorkBuddy 才生效。

验证连上了没

在对话框输入 现在几点？

能正常回答时间 = MCP 已连通 ✅
报 401 = Token 错了或过期 → 回 Step 1 重来
报「找不到 mcd 工具」= 配置没保存成功 → 检查 JSON 格式

STEP 3

导入 Skill

Skill = 让 AI 知道怎么玩这个游戏的操作手册 + 抽卡引擎。约 1 分钟。

克隆仓库

git clone https://github.com/ilAoC/mcd-gacha-collector.git

拷进 WorkBuddy 技能目录

# Windows
xcopy /E /I /Y mcd-gacha-collector\skills\mcd-gacha-collector "%USERPROFILE%\.workbuddy\skills\"

# macOS / Linux
cp -r mcd-gacha-collector/skills/mcd-gacha-collector ~/.workbuddy/skills/

验证

在对话框输入 抽张麦当劳卡，AI 开始问你位置 = 生效 ✅

💡 偷懒办法
直接在 WorkBuddy 对话框里说「找一下 mcd-gacha-collector 这个技能」， 让 AI 帮你完成安装。

⚠️ 安全机制

规则说明
必须先核价AI 一定先调 calculate-price，把总价（含优惠、配送费）念给你听
必须你点头只有你明确说「确认下单 / 买 / 就这个」，才会真正创建订单
不会乱下单你只是问「多少钱」「看看」时，AI 绝不会创建订单
取餐方式要选核价时会问你「堂食」还是「外带（取餐柜）」

下单常见问题

AI 说「这个商品该门店没在售」
门店菜单随时段变（早上早餐档、午晚正餐档）。换个时段再来，或换一家门店。
点餐时提示要 beCode
选「得来速（车道取餐）」时会需要。先用「到店自取」定位门店即可绕过。
能不能一次买好几张卡里的东西
可以。跟 AI 说「巨无霸三件套和麦辣鸡腿堡三件套都买」，AI 会一起核价给你确认。
价格和网页上不一样
正常。网页是展示用参考价，Skill 端是你所在门店的实时核价，后者才是真实应付金额。
FAQ

常见问题

一定要装 Skill 吗？
网页端不用装，直接开在线版就能玩抽卡与收藏册。
但要「门店定位」和「AI 帮你点餐」就必须装——公开展示版出于 隐私（定位会暴露访客大致位置）与资金安全（点餐会产生真实订单） 两方面考虑，已关闭这两项功能，网页会明确提示。
Token 会被上传吗？
不会。Token 只写在你本机的 MCP 配置里，AI 调用时直接向 mcp.mcd.cn 发请求。
抽到的卡能直接买吗？
能，这就是核心玩法——卡上带 product_code，下单时 AI 直接用门店编码下单，不用手输。
卡池有多少张？
网页端：96 张（73 张原卡 + 23 张独立闪卡变体），覆盖 13 个品类，100% 官方卡图
Skill 对话端：按你所在门店的实时菜单构建（30~90 张），时段不同数量不同，但价格准
稀有度怎么算的？
分层抽样：按价格分四层（≤15 / 15~30 / 30~50 / >50 元）， 每层内部按「价格 50% + 热量 30% + 蛋白 20%」的价值分排序，前 25% 为 SSR。 所以每个价格档里都有 SSR——15 元预算也能抽到金卡。
什么是金卡 / 银碎 / 闪卡？
纯装饰的卡面特效，与稀有度和健康度都无关：

👑 金卡 满卡鎏金粒子 + 金色光轮 —— SSR 34% / UR 5% / R 0%
🥈 银碎 银色箔片 + 冷光轮 —— SSR 30% / UR 22% / R 3%
✨ 闪卡 彩虹流光扫过 —— 独立卡项，SSR/UR 约 45% 有闪卡版
健康度和稀有度是一回事吗？
不是，正交的两个维度。
健康度回答「好不好」（依据《体重管理指导原则 2024》），稀有度回答「值不值得收集」。 贵的不一定健康，健康的不一定稀有。
